# Circular Flow Model

Interactive AP Macroeconomics diagram of the two-sector circular flow.

Households and firms exchange **real** resources and goods on the outer loop and **money** (costs, income, consumption, revenue) on the inner loop — through the resource market and the product market.

## Try it

```bash
npm install
npm run dev
```

Then open the app and:

- Click any sector, market, or flow to inspect it
- Toggle **Outer · real** / **Inner · money**
- Run the **guided tour**
- Pause or play the animated flows

## Stack

React 19 · TanStack Start · Vite · Tailwind CSS v4

Based on the classic closed-economy two-sector model (CELL: capital, entrepreneurship, land, labor).
